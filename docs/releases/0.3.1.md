This corrects the build provenance report shipped with 0.3.0. It includes
the guided pedal calibration, adjustable shift flashes and saved rev-light
colors from [0.3.0](https://github.com/crmne/omarchy-moza/releases/tag/v0.3.0),
with complete source metadata for build verification.

Download the [Linux x86-64 plugin archive](https://github.com/crmne/omarchy-moza/releases/download/v0.3.1/omarchy-moza-0.3.1.tar.gz).
The bundled executable is reproduced twice and attested before publication.

![Rev lights and pedal inputs, using simulated data](https://raw.githubusercontent.com/crmne/omarchy-moza/v0.3.1/preview.png)

## Fixed

- **Build reports always identify the exact source commit.** Archive-based
  CI checkouts have no Git metadata, which left `source_commit` empty in
  earlier reports. Generation now requires the workflow's full commit SHA,
  and publication checks that it matches the release. Missing or malformed
  commits and missing build metadata stop publication. Four regression tests
  cover these cases. By @crmne.

The earlier binary and report attestations still identify their source
commits. This patch corrects the downloadable report itself and prevents
the omission from recurring.

## Known limitations

Assetto Corsa needs the updated setup script's CSP companion. Hardware checks
cover an R12 with CS V2P, not every model; ARM64 needs a source build.
The [0.3.0 notes](https://github.com/crmne/omarchy-moza/releases/tag/v0.3.0)
describe the pedal calibration and shift-cue limitations.
