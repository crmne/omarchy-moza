The MOZA panel's number and text fields no longer read the clipboard. They
look the same, but are now built from key presses instead of Qt's text input,
which on Qt 6.12 reads whatever another application copies, at any size, even
while the field is hidden.

Download the [Linux x86-64 plugin archive](https://github.com/crmne/omarchy-moza/releases/download/v0.2.1/omarchy-moza-0.2.1.tar.gz), or install/update from the Omarchy plugin marketplace. The bundled x86-64
binary is unchanged from 0.2.0 and is verified again for this release.

![Rev lights and pedal inputs](https://raw.githubusercontent.com/crmne/omarchy-moza/v0.2.1/preview.png)

## Fixed

- **Settings fields never touch the clipboard.** Rev-light thresholds, LED
  count, slider values, preset names and LED colours take typed keys only.
  Focusing a number selects it so typing replaces it; Up/Down or the small
  arrows step it; Return or leaving the field applies it within range; Escape
  restores it. Scrolling the panel still never changes a value. Colour fields
  still accept `#RRGGBB`. Paste is no longer available in these fields.
  By @crmne; thanks @HANCORE-linux for identifying the clipboard issue
  during marketplace reviews.
