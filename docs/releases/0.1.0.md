# MOZA for Omarchy 0.1.0

Control MOZA hardware from the Omarchy bar, with Boxflat's settings and Rust
rev lights powered by moza-rev.

![Rev lights and pedal inputs](https://raw.githubusercontent.com/crmne/omarchy-moza/v0.1.0/preview.png)

- Configure wheelbases, wheels, pedals, shifters, handbrakes, dashboards and
  other Boxflat-supported devices through native themed controls.
- Use game telemetry for shift lights, with configurable first/full thresholds,
  LED count and a hardware test. The default range is 80–97% of redline.
- Read steering and pedal positions at up to 120 Hz while the panel is open.
- Save and apply Boxflat-compatible presets, including per-game profiles.
- Show the steering-wheel icon only when the wheelbase is connected; the
  service continues to detect reconnection while the icon is hidden.

Screenshots show the actual QML interface with simulated telemetry and inputs.
R12/CS V2P settings reads and the physical LED sweep have been checked. Other
hardware models still need testing. Firmware updates are outside Boxflat's
supported feature set.

See the [installation instructions](https://github.com/crmne/omarchy-moza#install)
for Python dependencies and device access. The repository includes an x86-64
Linux Rust executable and its source; other architectures build locally.
