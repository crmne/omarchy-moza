MOZA's Pedal Haptic Feedback module now works on Linux. The panel plays Pit
House's vibration effects on the clutch, brake and throttle from live game
telemetry, with the same settings and defaults. Assetto Corsa Competizione and
Le Mans Ultimate join the supported games.

Download the [Linux x86-64 plugin archive](https://github.com/crmne/omarchy-moza/releases/download/v0.4.0/omarchy-moza-0.4.0.tar.gz).
The bundled executables are built twice in a pinned environment and verified
before publication. The release includes their checksums and build provenance.

## New

- **Feel the car through your pedals.** With the Pedal Haptic Feedback module
  plugged into the computer, **Vibration module** offers engine vibration, gear
  shift, traction control, ABS, wheel spin, wheel lockup, brake threshold,
  clutch bite point and road texture, per pedal. Each has a switch, a Test
  button and Pit House's sliders, and defaults to Pit House's PHF-Official
  preset. The encoding and timings match Pit House 1.4.1.13's own traffic.
  By @crmne.
- **Effects follow each game's telemetry.** Assetto Corsa, Automobilista 2 /
  Project CARS 2, ACC and Le Mans Ultimate drive every effect. Forza drives all
  but ABS and TC, which it does not report. BeamNG drives engine, gear shift,
  ABS, TC, brake threshold and bite point. Other games drive engine vibration.
  By @crmne.
- **Rev lights and vibration in ACC and Le Mans Ultimate.** These games share
  telemetry only inside Proton, so a small bundled helper starts with the game
  through its Steam launch options. When either game is installed but not set
  up, the panel's header offers **Set up**: with Steam closed, it adds the
  helper to the launch options, keeping your own, and enables Le Mans
  Ultimate's plugins, after backing up each file. By @crmne.
- **Assetto Corsa sends what vibration needs.** The
  [Assetto Corsa setup](https://github.com/crmne/assetto-corsa-setup) companion
  now also reports gear, speed, pedal inputs, ABS and TC activity, wheel slip
  and suspension travel. By @crmne.

## Fixed

- **Other MOZA devices are never treated as the wheelbase.** With only the
  haptic module connected, the rev-light engine opened it as a wheelbase and
  showed the wheel as connected. The wheelbase now matches Boxflat's own base
  pattern. By @crmne.

## Known limitations

- The module must be plugged into the computer by USB. Connecting it behind a
  wheelbase is not supported yet.
- The ACC and Le Mans Ultimate helper relies on Proton's undocumented
  `PROTON_REMOTE_DEBUG_CMD`, present in Valve's Proton 8 to 11 and GE-Proton.
  If Valve removes it, these two games lose rev lights and vibration. ACC was
  verified with a stand-in for its shared memory; Le Mans Ultimate was tested
  on track.
- Wheel spin, lockup and road texture use thresholds of our own, not Pit
  House's. Automobilista 2's tyres slip often, so wheel spin there is busy.
  Automobilista 2 reports no tyre sizes, so slip effects start after the car
  has coasted straight for a moment.
- Assetto Corsa needs the updated companion; run the setup script with the
  game closed. Forza needs the **Dash** Data Out format.
- Hardware checks cover an R12 with CS V2P and the Pedal Haptic Feedback
  module with three actuators. ARM64 needs a source build.
