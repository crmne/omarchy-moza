The standard Omarchy plugin install command now leads into guided setup. If
Boxflat's dependencies or device-access rules are missing, the MOZA panel
offers a button to install them in an Omarchy terminal. It starts automatically
after setup. Existing device rules are preserved; newly installed rules need
the wheelbase and peripherals to be reconnected.

Boxflat now lives in a clearly separated, unmodified source snapshot with an
upstream commit, per-file hashes and a repeatable update command. The settings
engine remains Python, and the rev-light engine remains Rust. moza-rev stays
pinned to the fork revision that supports the tested CS V2P wheel.

The bundled x86-64 binary is built twice in a pinned environment and compared
with the committed executable. GitHub attests the verified binary and build
report, and release publication is gated on tests and verification.

Validation includes all 14 Boxflat sections, setup and failure handling, Rust
threshold tests and isolated QML captures. This retains the device logic
previously checked on an R12/CS V2P; that hardware was disconnected during the
0.2.0 packaging checks. ARM64 requires a source build. Other hardware still
needs model-specific checks.
